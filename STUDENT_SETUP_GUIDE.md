## 🔑 STEP 1: GET YOUR GROQ API KEY (5 minutes)

### **What is Groq?**
Groq provides the AI that powers MicroTrainer's teaching system. You need a free API key.

### **Detailed Instructions:**

#### **1.1 Go to Groq Console**
```
Open your browser
Go to: https://console.groq.com/
```

#### **1.2 Sign Up**
```
Click "Sign Up" or "Get Started"

Enter:
- Your email address
- Create a password
- Confirm password

Click "Create Account"
```

**💡 Tip:** Use the same email you used for your license request!

#### **1.3 Verify Your Email**
```
Check your email inbox
Find email from Groq
Click the verification link
```

#### **1.4 Log In**
```
Go back to: https://console.groq.com/
Enter your email and password
Click "Log In"
```

#### **1.5 Navigate to API Keys**
```
Once logged in, look at the left sidebar
Click "API Keys"
```

#### **1.6 Create New API Key**
```
Click "Create API Key" button
Give it a name: "MicroTrainer"
Click "Create"
```

#### **1.7 Copy Your API Key**
```
You'll see your API key (starts with "gsk_...")

Example: gsk_abc123def456ghi789jkl012mno345pqr678

⚠️ IMPORTANT: Copy this key NOW!
You won't be able to see it again!

Click "Copy" button
Paste it in a notepad or text file
Keep it safe!
```

**✅ Done! You now have your Groq API key!**

## 🚀 STEP 2: DEPLOY TO RENDER (10 minutes)

### **What is Render?**
Render hosts your MicroTrainer instance in the cloud. It's like having your own server!

### **Detailed Instructions:**

#### **2.1 Click Your Personalized Link**
```
Open the email from your instructor
Find the "Personalized Deploy Link"
Click the link

It looks like:
https://render.com/deploy?repo=...&env[LICENSE_KEY]=...

This opens Render's deploy page
```

#### **2.2 Sign Up for Render**
```
If you don't have a Render account:

Option A (Fastest):
  Click "Sign up with GitHub"
  Authorize Render
  Done!

Option B:
  Click "Sign up with Email"
  Enter email and password
  Verify email
  Done!
```

**💡 Tip:** Use GitHub signup - it's faster!

#### **2.3 Review Deployment**
```
You'll see:

Services to Deploy:
✅ microtrainer-backend (Node.js)
✅ microtrainer-piston (Docker)
✅ microtrainer-frontend (Static Site)

Plan: Free
Cost: $0/month
```

#### **2.4 Check Pre-filled Values**
```
You'll see these fields:

✅ LICENSE_KEY: your-email@example.com:abc123... (pre-filled!)
✅ STUDENT_EMAIL: your-email@example.com (pre-filled!)
✅ LICENSE_SERVER_URL: https://... (pre-filled!)
⬜ GROQ_API_KEY: [Empty - you need to fill this]
```

**💡 Notice:** 3 out of 4 values are already filled! You only need to add your Groq key!

#### **2.5 Paste Your Groq API Key**
```
Find the GROQ_API_KEY field
Click in the field
Paste your Groq key (from Step 1)

Example: gsk_abc123def456ghi789jkl012mno345pqr678
```

#### **2.6 Click Deploy**
```
Review everything one more time
Click "Apply" button
Deployment starts!
```

#### **2.7 Wait for Deployment**
```
Render will now:
✅ Create 3 services
✅ Install dependencies
✅ Build applications
✅ Deploy everything
✅ Connect services

You'll see logs scrolling:
"Installing dependencies..."
"Building frontend..."
"Starting backend..."
"Deploying Piston..."

⏳ This takes 8-10 minutes
☕ Perfect time for a coffee break!
```

**💡 Tip:** Don't close the browser! Keep the tab open.

#### **2.8 Deployment Complete**
```
When done, you'll see:

✅ microtrainer-backend: Live (green)
✅ microtrainer-piston: Live (green)
✅ microtrainer-frontend: Live (green)

You'll get 3 URLs:
- Backend: https://your-name-backend.onrender.com
- Piston: https://your-name-piston.onrender.com
- Frontend: https://your-name-frontend.onrender.com ← THIS ONE!
```

**✅ Done! Your MicroTrainer is deployed!**

## ❓ TROUBLESHOOTING

### **Issue: Can't create Groq account**
**Solution:**
- Check your email for verification link
- Try a different email address
- Contact Groq support: support@groq.com

### **Issue: Deployment failed**
**Solution:**
- Check that you pasted the Groq API key correctly
- Make sure all 4 environment variables are filled
- Check Render service logs for errors
- Contact your instructor

### **Issue: Frontend URL doesn't open**
**Solution:**
- Wait 30 seconds (services wake from sleep)
- Check that all 3 services show "Live" (green)
- Try refreshing the page
- Check your internet connection

### **Issue: License validation failed**
**Solution:**
- Check that LICENSE_KEY matches what instructor sent
- Check that STUDENT_EMAIL is correct
- Contact your instructor

### **Issue: Code execution not working**
**Solution:**
- Wait 30 seconds (Piston service waking up)
- Check that Piston service is "Live" (green)
- Try a different language
- Check the error message
