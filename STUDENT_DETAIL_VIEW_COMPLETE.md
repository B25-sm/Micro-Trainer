## 📊 Data Sources

The detail view pulls data from **4 API endpoints**:

1. **`/student/:id/analytics`** - Aggregated scores
2. **`/student/:id/memory`** - AI learning data
3. **`/profile/:id`** - Complete profile
4. **`/student/:id/history`** - Interview history (future)

**All loaded in parallel for fast display!**

## 🚀 Technical Details

### **Route:**
```
/trainer/student/:studentId
```

### **Example:**
```
https://your-app.vercel.app/trainer/student/student_123
```

### **Navigation:**
```javascript
// From dashboard
onClick={() => window.location.href = `/trainer/student/${student.studentId}`}

// Back to dashboard
onClick={() => navigate("/trainer")}
```
