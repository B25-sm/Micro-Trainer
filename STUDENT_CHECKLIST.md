# ✅ Student Deployment Checklist

## Before You Start

- [ ] I have a GitHub account
- [ ] I have a Render account (or will create one)
- [ ] I have 10 minutes of time
- [ ] I'm ready to learn!

---

## Step 1: Get Groq API Key

- [ ] Opened https://console.groq.com/
- [ ] Signed up (free account)
- [ ] Verified my email
- [ ] Went to "API Keys" section
- [ ] Clicked "Create API Key"
- [ ] Copied my key (starts with `gsk_...`)
- [ ] Saved key somewhere safe

**Time:** 2 minutes ⏱️

---

## Step 2: Deploy to Render

- [ ] Clicked "Deploy to Render" button
- [ ] Signed in to Render (or created account)
- [ ] Saw 3 services listed:
  - [ ] microtrainer-backend
  - [ ] microtrainer-piston
  - [ ] microtrainer-frontend
- [ ] Found `GROQ_API_KEY` field
- [ ] Pasted my Groq API key
- [ ] Clicked "Deploy" button

**Time:** 1 minute ⏱️

---

## Step 3: Wait for Deployment

- [ ] Saw "Building..." status
- [ ] Waited patiently (5-10 minutes)
- [ ] All 3 services show "Live" (green)
- [ ] No errors in logs

**Time:** 5-10 minutes ⏱️

---

## Step 4: Access My App

- [ ] Clicked on `microtrainer-frontend` service
- [ ] Copied the URL
- [ ] Opened URL in browser
- [ ] Saw MicroTrainer homepage
- [ ] Navigation works

## Troubleshooting

### If deployment failed:
- [ ] Checked if I added Groq API key
- [ ] Verified key is correct (starts with `gsk_`)
- [ ] Checked service logs in Render
- [ ] Tried redeploying

### If frontend won't load:
- [ ] Waited 2-3 minutes (services starting)
- [ ] Checked if all services are "Live"
- [ ] Refreshed browser
- [ ] Cleared browser cache

### If code execution doesn't work:
- [ ] Checked if Piston service is "Live"
- [ ] Verified code format: `function solution(input) { ... }`
- [ ] Tried simple code first
- [ ] Checked browser console (F12) for errors
